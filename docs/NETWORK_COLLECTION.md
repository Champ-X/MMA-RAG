# 网络素材采集

素材空间的「从网络导入」统一为「让 Agent 帮你找一找」。输入自然语言、HTTP/HTTPS 链接，或「网页链接＋获取要求」，选择自动收录或先看候选。目标空间在创建任务时固定，模型不能改变写入范围。

入口与左侧本地上传区上下对齐，主区域保留输入框、紧凑示例及查找按钮；收录方式与数量放在「查找选项」浮层中，展开不改变两列高度。「查看任务」位于 Agent 标题旁。提交后在弹窗内展示进度、历史、候选和收录结果；弹窗限定视口高度，内容独立滚动，操作按钮固定在底部。关闭弹窗不会取消任务或停止进度更新，再次点击「查看任务」保留当前任务与候选选择；重新进入空间时不会自动弹出历史任务。

搜索渠道不是素材站点白名单。专业图库用于提高搜索效率；通用网页搜索可以发现任意公开站点，公开网页读取器继续提取真实链接中的原文、PDF、图片、音视频文件。下载无需为每个网站单独编写适配器。

## 支持的流程

- 纯链接直接进入下载流程，不调用规划模型。
- 自然语言最多拆成三个查询；候选不足或主体不匹配时，允许一次基于反馈的查询改写或换渠道，整个任务最多四次发现调用。
- 「从这个网页找 PDF」等带链接的需求优先读取给定网页；不依赖搜索引擎密钥。只跟进用户提供或页面中实际出现的地址，模型不能凭空构造下载 URL。
- 普通公开网页发现最多读取三个页面；PDF 查找按目标数量最多读取十二个页面，仍只跟进一层中间页、每页最多 1 MiB，并共同受整次读取预算约束。识别 `href/src/srcset`、媒体标签及论文 PDF 元信息；下载时再次验证文件实际类型。
- 规划、候选筛选及必要的一次补搜规划复用现有 `intent_recognition`，单次模型请求限时 15 秒。严格检查具体主体和素材类型，图片需引用其实际元信息中的主体证据；不以广义相关凑数。
- 查找论文默认以 PDF 原文为交付目标；用户明确要求网页、摘要或混合素材时保留该要求。论文需求、文档格式和时间条件独立于搜索渠道保存，搜索结果页不能替代原始文件。规划使用当前日期解释「最近」，不会自行在查询中加入过时年份。
- 规划失败可降级为基础搜索；筛选失败时自动模式转为手动预览，用户选择后才收录。拒绝的候选不会在补搜中被自动补回。
- 筛选区分明确拒绝与本轮未选中，模型省略的候选可在补搜时重新判断；已接受的候选保留，不因后续模型漏选而消失。选择结论与理由冲突时转为人工确认。论文包含主题匹配的综述、方法和实证研究，只有用户明确限制时才缩小类型。
- 自动模式在数量上限内收录；审核模式保存候选，用户选择后再收录。明确的「两篇」「2 张加 1 篇」会转换为目标数量；表单数量是上限。
- 下载与解析由服务端执行，页面关闭不会取消任务。任务、候选、下载检查点、逐项处理身份和来源信息会持久化。
- 取消停止后续下载并等待已经开始的解析任务停止。重启后未完成任务显示为中断，用户继续时先核验已有处理回执；不会自动重新收录成功项。

## 渠道配置

| 渠道 | 需求 | 配置 |
| --- | --- | --- |
| 公开网页与文件 | 从用户链接发现正文、PDF、图片、音视频直链 | 无需搜索密钥 |
| Tavily | 全网网页、资讯及跨站原始资源发现 | `TAVILY_API_KEY` |
| Pixabay | 图片 | `PIXABAY_API_KEY` |
| Google Images / SerpAPI | 图片 | `SERPAPI_KEY` |
| Internet Archive | 图片馆藏 | 无需密钥 |

配置沿用后端环境。能力接口返回「已配置」状态，不将其等同于远端服务健康。权限、配额、超时、空结果和下载失败有不同错误码。没有搜索配置时，仍可粘贴可公开访问的链接，并说明要获取的内容；未知站点的全网搜索仍需要搜索渠道。

## API 与状态

基础路径为 `/api/collection`，沿用工作区访问规则：未配置访问令牌时只接受本机请求；远端部署需配置现有 `PI_AGENT_API_TOKEN`，复用工作区 Bearer/Cookie 校验逻辑；浏览器 Pi 会话 cookie 的路径限定为 `/api/pi`，采集请求应携带工作区 Bearer token。采集不要求开启 Pi 问答模式。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /capabilities` | 渠道状态及宿主限制 |
| `POST /runs` | `{kb_id,prompt,mode,max_items,client_request_id}` |
| `GET /runs?kb_id=…` | 恢复当前空间的最近任务 |
| `GET /runs/{id}` | 查询逐项进度 |
| `POST /runs/{id}/collect` | `{candidate_ids:[…]}`，收录审核候选 |
| `POST /runs/{id}/cancel` | 取消未完成工作，保留已有素材 |
| `POST /runs/{id}/retry` | 核验后继续失败或中断项 |

任务区分 `planning/searching/review/collecting/completed/partial/failed/cancelled/interrupted`。素材区分 `candidate/downloading/processing/ready/duplicate/failed/skipped`。候选不足且已选项均已处理时，界面引导调整需求，避免无效重试。

`ready` 需要解析回执中有非空索引、原对象仍存在，并按空间及文件身份读取当前向量计数；视频分别核验 Shot 与关键帧集合。摘要不代替原文：网页抓取正文生成 Markdown 后独立入库，保持来源记录。原页面、最终文件地址、搜索渠道、采集时间和内容哈希会进入来源元信息。当前不会自动生成跨文章综合摘要。

论文候选保留来源页面，同时保存已发现的 PDF 地址；标题打开原始来源，「打开 PDF 原文」访问文件。界面在下载校验前标为「PDF 候选」，成功收录后显示「PDF」。仅有 `required_format=pdf` 而没有文件地址时，不显示为已找到 PDF；无法获得所需原文时，不将网页摘要静默收录成论文。已完成的历史网页收录保留原格式，新能力不会自动覆盖旧素材。

PDF 获取复用通用公开页面读取器，识别 `citation_pdf_url`、bepress/eprints、Dublin Core、带 MIME 的嵌入文件，以及 JSON-LD 中的媒体下载地址；所有地址必须来自真实页面属性，模型不能生成文件地址。论文意图优先主论文元信息中的 PDF，跳过参考文献区域、明确标注的补充材料和附录。PDF 发现最多访问十二个页面，75 秒超时时保留已找到的文件候选并提示未完成的发现。

下载阶段遇到中间页时，最多额外访问四个实际出现的链接、跟进一层，只跟进明确的 PDF、下载、主文或全文入口。PDF 地址返回访问错误或 HTML 时，可回读来源页一次以重新发现文件；所有读取与最终文件共同计入下载预算，继续执行公网地址和重定向校验。下载与复用检查点都要求实际字节符合 `is_pdf_content` 的 PDF 文件头检查、MIME 为 `application/pdf`、文件名以 `.pdf` 结尾，再进入现有文档解析与索引流程；文件头通过本身不代表解析或索引已完成。

## 持久化与执行边界

默认状态目录为 `backend/data/collection`；托管安装使用 `TESSMORA_STATE_DIR/data/collection`。SQLite WAL 保存任务及同库 URL/内容哈希占用记录，`payloads` 保存已下载的检查点，`ingestion` 保存入库身份及来源回执。检查点用于显式恢复，不应在活动任务期间清理。

宿主使用进程锁：同一状态目录只允许一个采集执行进程。当前应用应使用单 API worker；多 worker 部署需要独立队列/worker，不能仅增加 Uvicorn worker 数量。

默认每次最多收录 20 项、40 个候选、四次发现调用；单素材下载 20 MiB，整次网络正文读取 50 MiB。网页发现与正式下载共同计账，失败和取消前已读取的字节也会持久化；搜索 API 的元信息响应另有限额。下载限制在流式读取时执行。公网地址在 DNS 解析后绑定已验证 IP，逐次重定向重新验证，保留 HTTPS 主机校验；只允许 80/443 端口。网页图片可作为显式候选选择，但正文解析器不会隐式触发二次下载。

入库复用现有租约、文档检查点、解析器和存储服务。采集项目生成稳定的文件、处理和向量身份，重复请求及恢复不会新增同一文件的副本。PDF 请求使用独立的 URL 占用类型，已有网页地址不会让 PDF 请求被误判为已完成的重复素材；内容哈希去重也要先核验原项的 PDF 格式证据与有效入库回执。去重范围为新采集流程内的同一空间；历史普通上传没有全局哈希目录，不声称能发现所有旧素材重复。

历史任务在收录或恢复时重新应用原始需求的格式约束。尚未开始入库的旧 HTML/Markdown 检查点不满足 PDF 要求时，可以重新下载原文；已开始入库的旧网页不会被原地改写成 PDF，会提示重新查找。已完成的网页任务和素材保持原样。

## 已知边界

- 选材依据搜索候选的元信息及模型相关性判断；未接入对所有图片进行视觉审美验收的模型循环。
- 发布时间缺失、授权不明确等情况会保留提示，不把未知条件视为已证实。
- 音视频支持从公开网页发现可下载文件，复用已有解析器；需要登录、受保护的播放器流、分片媒体流及超出限额的大文件尚不支持。
- 当前读取服务器返回的 HTML；仅由 JavaScript 动态生成的链接可能无法发现。浏览器自动操作、定时订阅及跨库整理不在本次实现范围。
- 持久化检查点暂不自动过期删除，需要保留以支持任务恢复。

## 验证

确定性测试覆盖请求幂等、跨进程执行互斥、工作区访问、跨空间隔离、审核不写库、候选选择、URL/hash 去重、已删除素材重新收录、丢失回执恢复、取消、下载预算、SSRF/重定向、模型降级和空索引拒绝。

```bash
PYTHONPATH=backend .venv/bin/python -m pytest backend/tests/test_collection_*.py -q
cd frontend
npm run type-check
npm run test:dom
```

真实供应商、浏览器和存储验收应另行执行；逐次回执保存在忽略的 `ops/` 或 `output/` 中。
