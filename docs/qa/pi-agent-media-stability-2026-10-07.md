第一份回答不能当作完整质量基准：它虽然展示素材，却声称未读取视频剧情，实际研究记录已包含若干视频索引片段。检索成功、保留在模型上下文、被最终正文使用、在界面呈现是不同的阶段。

## 设计改动

- `update_answer_plan` 由 Agent 登记全部交付项、用户原句和模态；首次登记后的要求不可删除或改写。素材选择与匹配依据分别记录，禁止用视频身份代替图片或音频。
- 当前选择及至多 8 条证据的逐字前 1000 个 Unicode 码点，在上下文归档和预算收尾后继续进入实际模型请求。记录截断范围，保留原始账本和引用身份；归档候选另保留有界的来源导航。
- 提交检查所有要点是否处理，并检查每条已选素材及支持依据是否进入正文数字引用。未取得的项目必须明确登记缺口，用 `partial` 交付，缺口进入最终限制说明。失败反馈由 Agent 自行修订，没有第二个回答生成器。
- 默认启用 `PI_AGENT_ANSWER_PLAN_ENABLED`；历史失败的实验性行级检查继续默认关闭。研究提示鼓励围绕缺口检索、限定来源、尽早选择；模型、温度、总预算、旧模式和已建索引保持原配置。
- 过程区显示实际回答要点、选择和证据按钮；刷新通过事件回放恢复。该状态明确表示 Agent 的理解与选择，不标为事实或语义已核实。
