## 通用调整

- 在系统提示、计划状态/提交工具说明、临近写作提示中，按用户交付结果判断完成度，不擅自增加权威认证、全量阅读、穷尽性证明等要求。必要来源说明由模型在正文末尾写一次，不影响状态。
- ready 表示该用户要求可以交付；incomplete 保留已有结果与证据，并记录该要求仍未交付的部分；unavailable 表示完全没有该项依据。全部 ready 只能 completed，真实缺口才允许 partial；limitations 必须与实际 gap 集合一致。
- 矛盾提交返回同一个 Agent 修订。没有宿主自动升级状态、改写正文、删除说明、引用后相关性筛选，也没有新增模型调用层。
- “禁止估算”与“允许未知占位”在提示中区分；用户只要求检查缺失时，缺失判断本身可以完成。仅依据给定记录的任务不应额外检索补齐事实。
- 原顶部“尚未覆盖”面板移到回答与引用之后，改为中性的“任务说明”，默认折叠；原始内容及历史状态保持不变。无说明时不渲染。
- 提示及执行分支不含本例片名、歌曲、文件名，按用户要求和结构化状态处理。运行预算仍未启用。
