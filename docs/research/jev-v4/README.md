# Jev 第四轮：逐段引用归属与生成服务接入

> 本文及回执保留第四轮的 `trailing-citations-v1` 结果。提取边界修复与可选批量诊断在[第五轮](../jev-v5/README.md)继续验证，当前代码已升级为v2；历史回执未改写。

2026-09-22。第三轮检查“整段答案是否被所引来源的并集支持”，本轮增加逐段归属检查，并接入真实普通/流式生成服务。它是一项默认关闭的诊断能力，**不会认证、拒绝或改写答案**。

## 实现与范围

[`jev_answer_audit.py`](../../../backend/app/modules/generation/jev_answer_audit.py) 识别普通段落/列表中尾随的 `[数字]` 引用组，将前面的局部文字与该组来源对应。每段只发送它自己的来源，不能借用另一句话的引用。前面的无引用句子不会自动继承末尾引用；句号后的紧邻引用也可识别。保留原答案字符偏移、声明哈希及引用 ID，诊断输出不复制声明或来源正文。

这是**语法层面的引用单元划分，不是完整的原子事实抽取**。代码块、标题、引用块、表格、无引用文字均保留为覆盖缺口；内联代码里的数组下标和 Markdown 链接不当作引用。跨句指代、复杂 Markdown 和跨段引用无法保证正确归属，多个断言共用一个引用组时仍作为整体判断。

每份答案最多审查 8 个单元、最多 16,000 字符；单元来源限额沿用第三轮，超限返回未评估，不截断成貌似完整的输入。图片/音频/视频来源不作文本支持认证。仅使用本轮调用方提供的已授权引用映射，未取回其他知识库内容。Jev 共享 worker 内预算与两个并发槽；本轮总等待 deadline 为 `JEV_TIMEOUT_S`，超时取消并等待所有未完成子任务结束，取消继续向上传播。

生产使用配置：

```dotenv
JEV_CITATION_MODE=shadow
JEV_TIMEOUT_S=3
TYPESAFE_API_KEY=<安全注入>
```

默认 `off`，不会建立 Jev 请求。`shadow` 表示只增加诊断，**不是无延迟后台执行**：普通响应会等待诊断；流式先下发正文和引用，再在 DONE 前等待诊断。已输出部分正文后遇到生成错误时不运行诊断，也不伪造成功完成事件。`JEV_RERANK_MODE` 继续推荐 `off`。

普通聊天将结果放入 `metadata.jev_citation_audit`，并把诊断耗时计入返回的处理时间。流式聊天在 `complete.diagnostics.jev_citation_audit` 暴露结果。前端没有新增“已验证”徽标或自动处理逻辑。

## 冻结错引与事实变异实验

数据位于 [`evals/jev_v4/attribution`](../../../evals/jev_v4/attribution)，由第三轮重放的 6 份真实历史答案产生，每份固定 5 种形式：原文、错引、数字/单位变异、缺失引用 ID、去掉引用。共 30 份答案；调用前冻结答案、预期标签和提取单元。这些是同源的压力样本，**不是 30 个独立业务问题，也不是新的检索运行**。

提示词、模型 `jev-1.13.0`、支持阈值 ≥0.8 沿用第三轮，没有按结果调优。原始答案及未变动单元标为支持；错引和变动事实标为不支持。标签由助手预先指定，未进行独立人工复核。

| 变体（各 6 份答案） | 引用单元 | 实际完成语义判断 | 发出支持信号 | 解读 |
| --- | ---: | ---: | ---: | --- |
| 原答案 | 11 | 11 | 9 | 2 个正确单元未被支持 |
| 错引 | 11 | 10 | 0 | 另 1 个请求超时，未评估 |
| 数字/单位变异 | 11 | 11 | 3 | 3 个未变动的正确单元通过；8 个变动单元均未获支持 |
| 不存在的引用 ID | 11 | 0 | 0 | 代码直接返回缺失来源，不调用模型 |
| 移除所有引用 | 0 | 0 | 0 | 报告 12 处未归属文字，不算通过 |

32 次语义判断成功，1 次在 5 秒总 deadline 到期；失败原始记录保留在 [attribution.jsonl](results/attribution.jsonl)。初次运行停止于该失败，检查后仅继续最后 3 个未运行样本，**没有重试超时样本或删除失败**。续跑沿用已有预算预留。

失败具体是 `system-11-off-wrong_citation`。因此只能说“18 个完成判断的错误单元没有误支持”，不能宣称全部 19 个错误单元都被准确识别。已知 usage 为 25,757 输入 token，估算 **$0.001081794**；计入未知计费请求保留的 4,258 token 预留后，预算记账为 30,015 token、**$0.001260630**，不是账户账单。

两个漏过的正确单元均来自英文答案：“The same document…” / “The documented default values in the same source…”。拆分后丢失了前句背景，Jev 判为证据不足，支持概率分别约 0.40 / 0.41。这说明逐段归属虽然避免借用别段来源，也可能损失指代上下文；不能把增加检查阶段等同于必然提高整体准确率。

## 真实生成链路

[`verify_jev_generation.py`](../../../backend/scripts/verify_jev_generation.py) 使用冻结的真实检索回执作为输入，调用实际 `ContextBuilder → GenerationService → 当前配置的 Kimi → Jev`，运行一次普通回答和一次真实流式回答。没有模拟模型输出；可选的相邻段落存储补充未接入，不连接存储服务。**这不是本轮重新执行入库、检索、HTTP 或浏览器验收。**

原始答案、引用映射、诊断与流式事件时序见 [generation-live.jsonl](results/generation-live.jsonl)：

| 运行 | 验证内容 | 诊断新增等待 | 生成至诊断完成 |
| --- | --- | ---: | ---: |
| 普通生成 | 苍鹭2026正式版限额600，引用ID有效，1个单元实际评估 | 0.919 秒 | 12.209 秒 |
| 流式生成 | 云杉审批链、48小时有效期、365天日志，3个单元实际评估 | 1.554 秒 | 22.366 秒 |

流式首个正文在 18.282 秒，末个正文在 20.808 秒，引用在 20.812 秒，DONE 在 22.366 秒。Jev 全部发生在正文输出之后，当前样本不会改变正文首次输出时间；网络抖动和并发下性能仍需另测。答案开头的引导句被保留为未归属文字，没有假装完整覆盖。

两次真实回答逐项与引用内容核对，数字、有效期、审批顺序均一致；4 次 Jev 调用成功，共 3,197 输入 token、估算 **$0.000134274**。费用不包含 Kimi；普通生成记录实际 usage，流式 manager 未在本回执返回完整生成 usage，不能编造成本。普通和流式生成不同问题，不能据此比较二者速度。

## 验证与复现

95 项相关回归通过，覆盖现有 Jev 合同/意图/评测、来源隔离、候选保护、检索效率、对话上下文，以及本轮新增的提取、部分 deadline、取消清理、默认关闭、普通生成结果保持、流式事件顺序和失败终态。最后对完成事件时间戳调整另跑了生成接入测试；详见 [verification.json](results/verification.json)。模拟调用仅用于故障和接口合同测试，以上质量与时间表均来自真实调用。

```bash
# 离线复算，无需 provider 配置或密钥
python backend/scripts/evaluate_jev_attribution.py

# 已冻结数据的全新真实运行，保留已有证据
python backend/scripts/evaluate_jev_attribution.py --live \
  --provider-env "$PROVIDER_ENV" --key-file "$KEY_FILE" \
  --output /tmp/jev-attribution-new.jsonl --report /tmp/jev-attribution-new.json

# 真实生成链路，输出路径必须不存在
python backend/scripts/verify_jev_generation.py \
  --provider-env "$PROVIDER_ENV" --key-file "$KEY_FILE" \
  --output /tmp/jev-generation-new.jsonl
```

默认研究预算 200,000 Jev 输入 token。发生失败时停止新增付费样本；`--continue-pending-after-review` 仅用于明确检查失败后继续尚未尝试的样本，保留错误与预留金额。不要用新文件反复重试失败以制造干净报告。

## 采用判断

现在已有可以运行的逐段归属诊断，并在真实普通/流式生成服务调用中完成验证。推荐维持默认关闭、按需开启 `shadow`：它能提供编号检查之外的语义信号，但存在遗漏、语法覆盖不足、指代丢失、额外调用费用和完成时延。不能将它用于自动认证、删证据或拒答。

后续可选研究包括保留有限指代背景的声明抽取、批量共享前缀、专用 NLI 对照和真实业务标注。这些方向尚无本项目收益证据，不属于本次已交付能力。跨轮方案与采用矩阵见[总研究结论](../JEV-DECISIONS.md)。
