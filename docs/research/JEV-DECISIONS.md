# Jev × MMA-RAG：跨轮研究、实现与采用决策

截至 2026-09-22，本工作树已完成五轮方案探索。目标是研究 TypeSafe.ai Jev 并实际尝试优化项目；不以“必须证明 Jev 全面更优”作为结论，也不把失败方案强行设成默认。

## 结论

| 方案 | 当前证据 | 实现/采用 |
| --- | --- | --- |
| Jev 替换 Qwen 精排 | v2 成功配对留出239题 nDCG@5 0.52643，Qwen 0.59394；差异区间支持退化 | 保留可复现 `shadow/replace` 实验能力，默认关闭 |
| Jev/Qwen 50:50 融合 | nDCG@5 0.57414，仍低于Qwen | 不采用 |
| Jev→Qwen 置信度级联 | 留出239题仍需227次Qwen，反事实P50约1.91秒 | 不采用，未宣称真实在线加速 |
| Jev 简单意图快路径 | 120题评测；12题真实系统配对Recall@5相同，P50 64.87→10.11秒；分布和区间有限 | 实现 `JEV_INTENT_MODE=adaptive`，默认关闭，复杂/不确定请求回退 |
| Choice引用支持诊断 | v3 留出24题三分类22对；16个负例零高分误支持，但8个正例仅支持6个 | 保留诊断，不自动认证 |
| 两个Noul支持/矛盾判断 | v3留出与Choice相同的支持召回，没有证明更优 | 作为实验诊断，不能称为独立双重核验 |
| 逐段引用归属与完成后诊断 | v4 30份相关变体、32次成功+1次超时；真实普通/流式生成均运行 | 实现 `JEV_CITATION_MODE=shadow`，默认关闭，明确覆盖缺口和新增等待 |
| 批量Choice引用诊断 | v5测试48单元与当前支持信号一致，输入用量减少47.09%；延迟差区间仍包含零 | 可选 `JEV_CITATION_STRATEGY=batch_choice`；默认仍per_unit，主开关off |
| 有限前文背景补救指代 | v5未恢复已知漏判，开发正例支持由9/11降到8/11 | 不采用；仅保留实验候选 |

Jev 是固定版本的托管窄语义决策模型，接受 state 和 Choice/Noul/Score typed questions；它不能替代本项目的开放式生成、向量嵌入、专用多模态理解或权限判断。官方和社区材料、模型公开缺陷与价格均保留原始快照及哈希，区分厂商/作者自报和本项目真实调用。

## 使用建议

重排维持 `JEV_RERANK_MODE=off`。需要尝试简单查询加速时单独启用 `JEV_INTENT_MODE=adaptive`；需要引用诊断时单独启用 `JEV_CITATION_MODE=shadow`。两个方向可以独立评估，不需要同时启用。Jev额度按worker生命周期共享，进程重启会重置，多worker不是账户全局限额。

完整业务数据标注、长期负载测试、专用分类器/NLI对照、自动事实修正、前端诊断呈现和生产发布均未交付，不应由本报告推导为已完成。现有实验已足以给出本次研究和尝试的采用判断；扩展上述能力需要新的明确实验问题和验收范围。
