## 旧模式并发隔离

真实协议固定同一问题，三个旧模式并发执行，并比较无 Pi / 两个 Pi 任务两种条件，先预热，再按 ABBA 次序进行。检查答案存在、引用预期论文、无流错误。预设延迟审查门槛为负载/对照中位数比不高于 1.25。

| 真实记录 | 每种条件的样本数/模式 | Auto 比值 | Direct 比值 | 旧 Agent 比值 |
| --- | --- | --- | --- | --- |
| `isolation-live.json`，资源优先级前 | 2 | **1.876** | 0.942 | 0.402 |
| `isolation-priority.json` | 2 | 1.017 | **1.408** | 0.982 |
| `isolation-priority-v2.json` | 6 | 0.851 | 0.915 | **1.497** |
| `isolation-diagnostics-v3.json`，修正重叠窗口并记录阶段 | 6 | 0.758 | 0.698 | 1.103 |

四份记录的答案/预期来源/无流错误检查均通过；前三份各有延迟门槛未通过，v3 三种模式均通过。来源命中不能代替语义质量评测，也不能据这些小样本建立稳定的 P95 或因果归因。

阶段记录显示一次 Direct 慢请求发生在两个 Pi 尚未调用模型或工具期间；旧检索查询向量阶段接近 12 秒。旧 Agent 的运行时间在有无 Pi 两种条件下都明显波动。v2 的重叠窗口还包含历史读取和健康任务收尾，不能把其中标记的每个事件当作实际旧 SSE 运行时的并发调用；脚本 v3 已修正，旧记录未被覆盖。

v3 请求级诊断共覆盖 36 条测量 SSE：旧 Agent 的对照组有一次额外搜索轮，负载组均一次规划即结束；保留了一次约 12 秒 embedding 超时及回退。对照/负载延迟中位数分别为 Auto 11.521/8.736 秒、Direct 11.140/7.778 秒、旧 Agent 12.444/13.720 秒。窗口内仅观察到 17 次 Pi 资源等待事件，没有新的模型或工具准入；因此该检查主要验证旧请求优先调度，不能据此覆盖已经在途的 Pi 模型调用。原始阶段记录为 `diagnostics-v3/spans.jsonl`，分析为 `diagnostics-v3-analysis.json`。

随后增加固定外部响应的受控检查，记录为 `isolation-controlled-v1.json`：每种模式各 8 个对照和 8 个负载样本，走真实旧 HTTP 边界、旧 Agent 循环、Pi 宿主及 Node 进程。模拟外部检索/生成响应固定。旧请求先进入，两个 Pi 任务随后等待，旧请求完成后 Pi 恢复并正常结束。

| 固定外部响应 | Auto | Direct | 旧 Agent |
| --- | --- | --- | --- |
| 延迟中位数比 | 1.0075 | 1.0078 | 1.0013 |
| 答案与引用 | 完全一致 | 完全一致 | 完全一致 |

该结果支持已测试调度路径的低开销与协议隔离；不覆盖已经发出的 Pi 推理/媒体调用，也不证明共享供应商配额或 Qdrant 在所有负载下都无影响。默认优先级会让 Pi 等待，等待计入运行预算。部署时可配置 Pi 专用模型端点/凭证，但当前验证仍使用共享本机存储和部分供应商配额。

## 跨问题与在途模型检查

先冻结 `quality-cases-v1.json`（SHA-256 `3f14104447cf9d02468458faa5be9862fda7decd383279cf665645fb0dc8aa6b`），覆盖七层分类、AHE 三种可观测性、数字与百分点、跨论文比较、指定文件范围及无答案六题。参考事实来自已保存的实际原文，并保留来源版本及正文哈希。每题运行三个旧模式的对照/负载条件，再运行 Pi，共 42 份回答记录，保存为 `quality-v1/`。

负载条件先等待两路 Pi 的 `model.started`。12 次 Pi 主模型调用均与旧 SSE 窗口实际重叠，耗时约 0.63–1.57 秒；后续研究调用继续服从旧请求优先级。36 条旧模式响应没有流错误，引用编号均能匹配返回来源，指定文件题没有越界。

内容审阅发现：可回答题的关键数字及分类没有新矛盾，但旧模式在框架运行时取舍题的两种条件下都遗漏了镜像体积和启动延迟；跨论文题的 Direct 负载答案也更简略。无答案题的 Auto 与旧 Agent 负载答案附了无关来源，而各自对照未附。**因此预设的严格实时配对质量门槛没有全部通过。** 相同生成文本经 `bf9627b` 的引用选择器重放，仍保留完全相同的引用；旧检索、生成、Agent 和模型管理模块与基线无差异，见 `legacy-no-evidence-baseline-replay.json`。这确认既有引用合同的缺陷，不能据此证明随机生成质量的统计非劣效性。

Pi 首轮暴露两项缺陷：跨论文题在已有证据后耗尽下一轮上下文预算；无答案题仍引用论文题录。这两份失败未替换。修复后保持原六题、原预算，另存 `quality-pi-v2/`，逐题执行一次：

| Pi 问题 | 后续结果 | 观察边界 |
| --- | --- | --- |
| 七层分类 | completed，37,059 Token | 七层及核心/控制面分组有对应原文 |
| AHE 可观测性 | completed，85,416 Token | 三种机制对应实际正文引用 |
| 十轮增益 | completed，62,127 Token | 69.7% → 77.0%，7.3 个百分点；固定基础模型有依据 |
| 跨论文比较 | completed，121,589 Token | 实际触发一次预算收尾，交付答案及未深读范围；部分依据是图注/索引描述，不能称为全篇核验 |
| 文件范围 | completed，34,672 Token | 仅返回指定综述，包含镜像、启动与耦合的取舍 |
| 无答案 | partial / not_found，63,391 Token | 未编造营收，引用为空；搜索范围与未查询外部来源均有说明 |

后续六题的引用编号均完整匹配实际交付证据。关键事实与引用由本次实现 Agent 对照冻结材料逐条审阅，未使用独立盲评；部分回答超出所要求的篇幅，负面断言仍需注意搜索未命中与全篇不存在之间的区别。此结果证明已观察到的预算/空引用缺陷得到处理，不是广泛业务准确率或多模态语义质量结论。

剩余边界包括：共享供应商配额及较长媒体调用的争用、更多业务语料的独立语义评测、旧模式既有无依据引用，以及模型对篇幅与证据深度要求的遵循。不得把代码隔离、固定响应一致或最新延迟门槛通过写成上述边界全部消除。
