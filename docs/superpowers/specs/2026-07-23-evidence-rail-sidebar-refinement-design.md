# Evidence Rail 侧栏视觉与交互优化设计

**日期：** 2026-07-23
**范围：** Nexus（MMA-RAG）会话页左侧统一导航与会话栏

## 1. 目标与约束

本轮优化面向使用 Nexus 进行多模态知识检索、需要频繁在会话与知识库之间切换的研究型用户。侧栏的唯一工作是让用户快速辨识当前工作上下文并切换，而不是承载品牌海报或卡片集合。

目标：

- 将当前浅色、粗紫色、卡片感偏强的左栏重塑为深石墨色的“Evidence Rail”。
- 参考 `enhance` 分支的视觉 token、紧凑排版、细分隔线、内嵌活动态和响应式理念；不复用其功能、组件架构或业务逻辑。
- 保留圆形 Nexus Logo，并将它作为简洁的品牌锚点。
- 统一采用圆角语言，同时避免每个元素都成为独立悬浮卡片。
- 保持会话创建、切换、删除、导航、主题切换、会话数据和 SSE 流式行为完全不变。

非目标：

- 不改动 `useChatStore`、后端 API、路由、会话排序或持久化格式。
- 不迁移 `enhance` 分支的组件、CSS 文件或页面结构。
- 不扩展项目分组、搜索、置顶、重命名等新功能。

## 2. 视觉方向：Evidence Rail

侧栏使用深石墨作为稳定的“工作台边界”，将主内容区留给阅读和检索。钴蓝只承担主动操作与键盘焦点，青绿色只承担当前检索上下文；两者不会同时大面积出现。

### 色彩 token

| Token | 色值 | 用途 |
| --- | --- | --- |
| Rail obsidian | `#131B1E` | 侧栏基础底色 |
| Rail graphite | `#1B272A` | 悬停、当前会话底色 |
| Rail rule | `#2D3B3E` | 分隔线与静默边框 |
| Rail ink | `#E9F0EE` | 主要文字与 Logo 周边高对比内容 |
| Rail muted | `#91A09E` | 辅助标签、计数、未选图标 |
| Cobalt action | `#5D76FF` | 新建对话、焦点、活动态起点 |
| Teal evidence | `#55C5A7` | 当前会话“证据缝线”的终点 |

深色主题继续沿用应用现有逻辑；浅色主题下侧栏仍维持深石墨，不随主区变为白色，从而固定空间边界并增强 Logo 对比度。

### 字体与圆角

- 主文本沿用现有中文系统字体，保证中文会话标题密度和可读性。
- “最近会话”、数量、工作区描述等使用小号等宽字和较宽字距，承接 `enhance` 分支的工具性层级。
- 控件采用一致的圆角：列表行与导航项为 10px，按钮为 12px，Logo 容器和当前会话区域为 14px。圆角用于柔化密度，而不引入白底卡片。

### 专属记忆点

当前会话左边缘展示 3px 的“证据缝线”，从钴蓝渐变至青绿。它只出现在当前会话上，表达多模态检索链路，而不是作为通用装饰或按钮渐变。

### 品牌区

- 保留彩色圆形 Logo，但缩为 34–36px，置于深色圆角承托中。
- “Nexus”使用紧凑主文字；“evidence workspace”采用小号等宽辅助标签，取消大写大字距造成的横向拉伸感。
- 收起按钮以低对比图标按钮呈现；不使用白色浮动圆形按钮。

### 主动作与导航

- “新建对话”保持全宽圆角按钮，但高度收为 40px，去除过强的外发光与渐变；按钮只有钴蓝色面和轻微阴影。
- 知识库、架构、设置采用 38–40px 紧凑行高，图标和文字对齐到同一基线。
- 导航悬停使用 Rail graphite；活动页使用内部 3px 钴蓝线，不使用整块高亮或白底。

### 会话列表

- 标题区以“最近会话”加等宽计数构成，不再使用笨重标签块。
- 移除方形首字母块，默认行保持文字优先；只有当前项显示 Graphite 背景和 Evidence Seam。
- 删除操作默认隐藏，在桌面悬停或键盘聚焦时出现；删除回调不变。
- 超长标题截断，并保持原生 `title` 文本提示；会话列表继续独立滚动。

### 底部工具区

- 主题切换和用户身份不再被各自白色卡片包裹；它们是通过顶部细分隔线收束的静默工具行。
- 用户区域保留小圆形头像，并以主/辅助两行文本表示身份与工作区。

## 4. 动效、响应式与可访问性

- 悬停、选中、展开、删除显现使用 140–180ms 的颜色与透明度过渡；不新增连续动画。
- 检测 `prefers-reduced-motion` 后取消平滑滚动和非必要位移动画。
- 保留现有的 `aria-label`、`title`、键盘焦点、会话选择按钮语义与删除按钮可访问名称。
- 桌面端维持约 278px 展开宽度和 76px 图标轨；手机宽度下使用图标轨以保护主内容宽度。
- 收起状态隐藏文字但保留工具提示，当前会话仍以 Evidence Seam 和首字母标识可辨。

## 5. 实现边界与验证

主要修改范围：

- `frontend/src/components/layout/ConversationSidebar.tsx`
- 如需调整深色工作区衔接，最小化修改 `frontend/src/components/layout/AppLayout.tsx`

不修改：

- `frontend/src/store/useChatStore.ts`
- `frontend/src/components/chat/ChatInterface.tsx` 中的消息、输入、引用、附件与流式逻辑
- 后端接口和路由定义

验证清单：

1. 在桌面端检查品牌区、新建按钮、导航、当前会话、长会话列表和底部工具区的层级。
2. 检查浅色与深色主区下的深石墨侧栏对比度和文字可读性。
3. 检查窄屏图标轨、展开/收起、焦点样式和工具提示。
4. 验证新建、选择、删除会话与切换知识库、架构、设置入口仍使用原有回调。
5. 运行 TypeScript 类型检查，并使用浏览器检查无运行时错误、无空白页、无错误覆盖层。
