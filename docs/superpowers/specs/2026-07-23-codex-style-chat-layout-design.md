# Codex 式会话主页面改版设计

**日期：** 2026-07-23
**范围：** Nexus（MMA-RAG）Web 前端的会话主页面

## 1. 背景与目标

当前会话页由深色的 64px 全局图标栏、顶部横向会话标签和中央对话区组成。横向标签在会话增多时难以浏览，也让主工作区承担了会话管理的职责。

本次改版将其调整为 Codex 式的统一左侧工作栏：功能导航和会话列表集中在一个更宽的侧栏中，主工作区只聚焦当前对话。会话无需按知识库或项目分组，按现有会话顺序显示即可。

成功标准：

- 在桌面端可直接浏览、创建、切换和删除会话。
- 保留知识库、架构和设置入口，以及全部现有对话能力。
- 不改变 `useChatStore` 的会话数据、SSE 流式回复和会话持久化行为。
- 在窄屏、深色主题和键盘操作下仍可用。

## 2. 信息架构与布局

### 桌面端

页面改为两栏布局：

```text
┌──────────────────── unified sidebar ────────────────────┬──────── workspace ────────┐
│ Nexus 标识                                      收起按钮 │ 当前对话内容               │
│ [ + 新建对话 ]                                            │                              │
│ 知识库 / 架构 / 设置                                      │ 消息、思考链、引用          │
│ ──────────────────────────────────────────────────────── │                              │
│ 最近对话                                                  │                              │
│   当前会话（高亮 + 检索信号线）                           │                              │
│   其他会话（悬停显示删除）                                │                              │
│   更多会话（列表独立滚动）                                │                         输入框│
└─────────────────────────────────────────────────────────┴──────────────────────────┘
```

- 左栏宽度为约 280px，背景为浅色实底；它替代原本的深色图标栏和顶部横向会话标签。
- 顶部包含 Nexus 标识、可访问的收起按钮，以及全宽的“新建对话”按钮。
- 功能导航固定在会话列表上方，仅保留知识库、架构、设置三个“图标 + 文字”入口。“新建对话”既创建会话，也作为返回会话工作区的唯一主入口，因此不再设置重复的“对话”导航。
- “最近对话”区域占据剩余高度且独立滚动。会话以扁平单行列表展示，不引入项目或知识库分组。
- 主区移除 `ConversationTabs`，消息阅读列保持居中并限制合理最大宽度；现有底部输入器继续固定在对话区底部。

### 窄屏

- 侧栏可收起为仅图标的窄轨；主区仍保持可用宽度。
- 收起状态下提供工具提示和可访问名称，保证入口仍可识别。
- 不改变会话页常驻挂载的策略，离开再返回对话页时不应中断 SSE 流。

## 3. 视觉系统

设计主题为“知识工作台”，避免把 RAG 工作流做成装饰性仪表盘。

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 页面底色 | `#F8FAFC` | 安静、连续的主工作区背景 |
| 主要文字 | `#182230` | 保证中文长文本阅读对比度 |
| 分隔边框 | `#E6EAF0` | 用于栏位和列表层级，不形成卡片堆叠 |
| 品牌强调 | `#5B5CEB` | 仅用于当前导航、主要操作和焦点状态 |
| 检索信号辅助色 | `#22B8A6` | 与靛蓝共同构成当前会话的细小标记 |

- 主体使用现有应用的系统字体栈和紧凑字级，避免引入额外网络字体或改变中文渲染。
- 侧栏以 1px 分隔线、克制的 hover 背景和稳定留白建立层级，而非厚重阴影、渐变背景或大圆角卡片。
- 当前会话的专属记忆点是一条左侧“检索信号线”：从靛蓝过渡到青色，表达 Nexus 的多模态检索链路。它只出现在选中项上，不参与其他装饰。
- 明暗主题沿用已有主题机制，深色版本保持相同的信息层级和品牌色含义。

## 4. 组件与数据边界

### 新增或调整的组件

- `ConversationSidebar`（新增）：呈现品牌头部、全局导航、会话列表和新建会话入口。它接收会话数组、活跃会话 ID 和回调，不直接修改 store；点击“新建对话”时由上层先导航至会话工作区，再创建会话。
- `AppLayout`（调整）：在会话页渲染统一侧栏；继续负责路由视图的常驻挂载和主题切换。
- `ChatInterface`（调整）：移除顶部 `ConversationTabs` 的渲染；保留消息区、输入器、附件、引用、模型和知识库配置。
- `ConversationTabs`（退役）：不再作为主页面的一部分。其现有的选择、创建、删除交互迁移至 `ConversationSidebar`。

### 数据流

```text
useChatStore
  ├─ sessions / activeSessionId ──> ConversationSidebar（展示）
  ├─ createSession ───────────────> 新建对话
  ├─ switchSession ───────────────> 选择会话
  ├─ deleteSession ───────────────> 删除会话
  └─ getActiveSession ────────────> ChatInterface（当前对话内容）
```

- 不新增会话分组、项目字段或后端 API。
- 会话标题继续取首条用户消息或现有 `title`；超长标题截断并通过原生 `title` 提供完整文本。
- 删除按钮仅在存在多个会话时显示，沿用 store 中“至少保留一个会话”的保障。

## 5. 交互、可访问性与异常状态

- “新建对话”始终可见；它既是会话工作区的主入口，也是创建动作。点击后先进入会话页，创建并选中新会话，最后使列表滚动到可见位置。
- 当前会话有明显的背景、文字和检索信号线差异；其他会话悬停时显示轻量删除操作。
- 所有图标按钮提供 `aria-label`、标题提示和可见键盘焦点；会话选择控件用按钮语义实现。
- 会话较多时仅会话列表滚动，侧栏的品牌、功能入口和新建按钮不随之离开视野。
- 空会话、删除最后一个会话、标题为空和流式生成中的会话切换均复用现有 store 行为；不新增阻断性弹窗。
- 对长标题、缩窄视图和深色主题的样式均要避免文字溢出或低对比度。

## 6. 实施与验证

预计涉及：

- `frontend/src/components/layout/AppLayout.tsx`
- `frontend/src/components/chat/ChatInterface.tsx`
- `frontend/src/components/chat/ConversationTabs.tsx`（移除使用或退役）
- `frontend/src/components/chat/ConversationSidebar.tsx`（新增）

验证清单：

1. 桌面端检查左栏、长会话列表和主对话区布局。
2. 窄屏下检查侧栏收起/展开后仍能导航和切换会话。
3. 验证创建、切换、删除会话以及删除仅剩会话时的行为。
4. 发送一条消息并在流式回复时切换页面/会话，确认流没有因布局变更而中断。
5. 检查浅色和深色主题的对比度、hover、焦点和活动状态。
6. 运行前端 lint、TypeScript 类型检查与生产构建。

## 7. 非目标

- 不增加项目、知识库或时间分组。
- 不改造消息格式、检索流程、模型配置、附件能力或后端接口。
- 不引入新的设计系统、第三方 UI 库或远程字体依赖。
