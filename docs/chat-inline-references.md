# 行内文件引用与本机附件

输入框使用 Tiptap 的原子节点承载引用，保留编辑器的光标、撤销、选区和中文输入行为。编辑器按需加载。图片显示缩略图；音频显示封面（若有）或音乐标识。知识库引用使用实线与空间名，本机附件使用绿色虚线与“本机”标签。

## 交互约定

- `分析这张图@空间/文件` 不要求在 `@` 前加入空格；邮箱不触发菜单。
- `@本机/文件` 与 `@附件/文件` 搜索本轮上传，菜单与知识库文件分组。
- 同一文件可以重复引用；各处独立删除，检索范围按文件去重。
- 附件卡片上的 `@` 在光标处插入引用。移除上传附件会同时移除它的行内引用，并重置编辑历史，避免撤销恢复悬空附件。
- 文件范围选择器同时反映行内知识库文件。移除范围中的行内文件也会移除相应引用；删除一个行内节点不影响仍被其他节点引用的文件。
- Enter 发送，Shift+Enter 换行；候选菜单支持方向键、Enter/Tab 和 Escape。组合输入期间不发送。
- 粘贴只接收纯文本，不接受外部 HTML 构造的文件身份；复制到纯文本时保留 `@文件名`，需要重新选择才成为绑定引用。
- 每条用户消息在鼠标悬浮或操作按钮获得键盘焦点时显示复制、编辑按钮。复制完整原文（含换行及 `@文件名`），剪贴板被拒绝时明确提示，不能假报成功。
- 编辑恢复到输入框，修改后作为新一轮重新检索生成，保留原对话。输入框已有草稿时暂存，取消编辑或提交成功后恢复；切换编辑对象仍保留最初的草稿。请求进行中禁用编辑。
- 编辑恢复原始附件二进制，为本轮生成新附件 ID 并重绑所有出现位置；缺少原文件时保持草稿不变并提示重新添加，不用缩略图或摘要代替原件。行内知识库文件跟随引用节点，不额外恢复为固定范围；独立选择的其他文件继续保留。
- 消息附件仅展示缩略图或播放器，不再在下方重复显示“本机 · 已解析”等文字；消息正文也不再另列知识库文件路径。

## 提交契约

`message` 是包含 `@文件名` 的纯文本；`mentions` 独立保留各次出现的位置：

```json
{
  "source": "attachment",
  "attachmentId": "upload-id",
  "name": "山水.png",
  "type": "image/png",
  "start": 2,
  "end": 9
}
```

`start/end` 是 **相对于完整 message 的 UTF-16 code unit 偏移**，end 不包含在区间中，与浏览器字符串一致。知识库引用使用 `source=knowledge`、`kbId`、`fileId`、`kbName`；multipart 的 `attachmentIds` 与文件上传顺序一一对应。预览 URL 不进入提交或持久化的引用数据。

multipart 同时传 `messageJson=JSON.stringify(message)`，服务端以解码后的原文为准。浏览器会将普通表单字符串中的 LF 换行改为 CRLF，直接使用普通 `message` 字段会使第二行起的引用偏移失效。JSON 转义保留原始换行、空行、前导空格和 Unicode 字符；旧客户端只在原文校验失败、且还原 LF 后所有位置与身份均通过校验时兼容恢复，不按文件名猜测新位置。

后端检查位置、名称、重叠、来源、知识库范围及上传标识；过期或伪造的引用在模型调用前失败。不能仅按文件名匹配。同名文件与重复引用使用稳定身份区分。

请求校验失败以 `stage=validation` 返回，附件解析失败以 `stage=attachment` 返回；界面区分这些失败与模型生成失败，同一错误只显示一次。失败消息提供“编辑后重试”，从浏览器附件存储恢复原文与上传文件，重新建立本轮附件标识；浏览器已清理原文件时明确提示重新添加。

Direct 与 Agent 均收到在原句位置标记的对象和来源映射；检索仍受原有 `selected_files` 约束。本机附件不会被当作知识库文件筛选条件。生成保留同一份映射，并区分本机解析证据和知识库编号引用。

## 附件解析

- 保持原有图片/音频范围，每轮最多 3 个，每个 10 MiB；服务端有限读取、媒体头检查，并用 Pillow / ffprobe 核验实际媒体。
- 图片读取尺寸；音频读取时长、采样率、声道数，并按实际容器确定模型输入格式。依赖项目已有 Pillow、FFmpeg/ffprobe。
- 并发解析，每项 120 秒超时，各自返回 ready/failed。单项失败不抹去成功项；全部失败结束请求，不继续用失败文本生成答案。
- 针对问题保留视觉特征、语音事实、音乐音色和结构等信息；通常请求 200–600 字，密集信息最多 1500 字，代码上限为每项 1800 字。各项独立限额，不再用 900 字总截断吞掉后面的文件。
- 本地实测信息优先于模型推断；明显超出实际时长的音频时间描述判为失败。该校验**不等于**音乐语义、乐器、音高或画面细节的正确性认证；模型观察仍可能不准确。
- 生成上下文压缩保留引用映射与附件证据，且保留音频/视频类型。附件不写 MinIO/Qdrant、不重新解析现有知识库。
- 历史保存引用、附件身份、解析状态、实测信息和摘要；后续轮次在现有历史字符预算内使用记录。原始附件仍在浏览器 IndexedDB，服务端不持久保存原始二进制；摘要不能替代完整原件或无限多轮记忆。
- 流式请求中断且没有结束事件时显示错误，不让输入框一直等待。
