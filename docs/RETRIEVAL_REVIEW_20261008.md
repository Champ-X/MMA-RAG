# 检索评测复核：替代证据、Pi 观察与最终引用

这轮完善了评测工具，并用已保存的回执离线复算。**没有重新请求模型、重试失败、修改生产检索参数或重新入库。分数变化来自标注修订与评分阶段的区分，不代表 Pi 模型行为得到提升。**

[原始实验](RETRIEVAL_EVALUATION_20261008.md)及其完成审计全部保留。新增[机器可读汇总](../evals/retrieval_v2/review-20261008/summary.json)独立发布；私有标注、逐题结果、原始图片和答案复核包位于被 Git 忽略的 `data/retrieval-evaluation-20261008/review-v1/`。

## 修正了什么

1. **接受有来源的等价证据。** 复核 3 道文本题的 4 个证据组，补入原文中等价的定义、故障归因和权限说明。保留原有标签；替代方案之间为 OR，同一方案需要多项事实时仍为 AND。缺少关键约束的候选段落未被接受。修订对 Direct、常规 Agent、Pi 统一生效。
2. **拆开研究观察与最终引用。** Pi 研究阶段按首次观察顺序统计；答案阶段按正文中数字引用首次出现的顺序统计，不能用引用数组排序替代。未核验的媒体观察保留位置，不因未评分而将后续证据提前；无效引用占位且不得分。
3. **对原始图片做窄范围复核。** 检查一道跨模态题的两张原始图片，字节 MD5 与原始任务记录的来源版本一致。目标海报支持烟囱锚点，室内合照不支持。正向判定绑定具体来源、观察、原始字节及证据锚点，不等于核准模型的所有描述或完整答案。
4. **把语义质量的未知值保留下来。** 输出 80 份私有答案复核包，支持绑定答案/任务哈希、有评审来源的正确性、引用支持度与拒答判定。没有完整评审时，整体语义分数为 `null`；超时失败按零计入操作性任务分母。
5. **为同预算对照设置前置检查。** 必须具有相同数据、阶段、排序、工具实现、模型栈、并发和预算契约，并提供逐题执行回执。历史实验缺少这套约束与回执，因此门禁拒绝将其标为同预算比较。

本次修订参考了已观察到的失败，评审由 Agent 完成，**属于非盲的事后开发诊断，不再是未接触过的保留集**。它修补了已发现的标注遗漏，没有证明所有其余标签都完备。

## 同一标注修订下的索引证据复算

分母均为 76 道有必需证据标注的题，失败计零。下表保留各模式原先的证据顺序及执行预算，仅修改证据标签；Pi 在这一表中仍不包含新媒体观察。

| 模式 | 原始前 5 条 | 修订后前 5 条 | 原始集合 @50 | 修订后集合 @50 |
|---|---:|---:|---:|---:|
| Direct | 61/76（80.26%） | 62/76（81.58%） | 61/76（80.26%） | 62/76（81.58%） |
| 常规多轮 Agent | 68/76（89.47%） | 70/76（92.11%） | 74/76（97.37%） | 76/76（100.00%） |
| Pi Agent | 65/76（85.53%） | 66/76（86.84%） | 71/76（93.42%） | 73/76（96.05%） |

常规 Agent 的修订后集合覆盖为 100%，只表示这 76 道题在修订标签下的已保存集合覆盖。它不能代表真实用户整体准确率，也不是新增独立测试结果。三种模式预算仍不同。

## Pi 的不同阶段不能混为一个排名

以下使用修订标签，并纳入两项已核验的原始图片锚点判定。其余媒体观察保守不授予证据分，单独保留未判定数量。

| Pi 阶段 | 前 5 条证据齐全率 | 集合 @50 证据齐全率 |
|---|---:|---:|
| 研究观察，含媒体占位 | 67/76（88.16%） | 74/76（97.37%） |
| 最终答案的引用，按首次出现顺序 | 73/76（96.05%） | 74/76（97.37%） |

研究观察前 5 条未找齐的 9 题中，6 题在最终前 5 个引用中已经齐全。最终前 5 个引用仍未齐全的 3 题中，1 题在后续引用中补齐，1 题仍未满足标注的完整定义，1 题为真实预算取消。**观察阶段的前列分数不能直接代表 Pi 最终的证据选择效果。**

这也不能将 Pi 的 96.05% 与常规 Agent 的 92.11% 当作同阶段优劣结论：前者是生成答案后的引用，后者是交给生成器的检索集合。历史 Direct/常规 Agent 记录未保存最终答案，缺失阶段不填零分。

80 个 Pi 任务包括 76 个 `completed`、3 个 `partial`、1 个 `cancelled`，其中 79 个有答案文本。未发现引用编号、来源身份、内容或所属任务不匹配，但这项结构检查不能证明引用支持结论。研究观察中仍有 45 个未核验观察，最终引用中有 43 个；它们是观察数量，不是题目数量。

答案正确性、引用支持度各有 79 题待语义评审，另 1 题操作失败计零；4 道无答案题的正确拒答判定全部待评审。整体三个语义指标均保持未知。图片复核只确认现有金标准中的烟囱特征，未确认画面外的裤装，也未把整道题升级为语义正确。

## 工具入口与验证

命令详见[评测协议](RETRIEVAL_EVALUATION_V2.md#标注修订与分层复核)。新增命令：

- `revise-labels`：来源校验后生成新数据版本，不允许覆盖原目录。
- `replay-labels`：先精确复算原始报告，再在同一批记录上更换标签；来源、查询、范围、排序、失败、时延和用量保持原样。
- `audit-pi`：核对原始任务文件哈希及索引证据，生成私有分层报告、答案复核包和可公开汇总。
- `comparison-readiness`、`compare --require-matched`：检查比较条件。正常描述性比较仍可进行，但不能标为同预算优劣。

`scripts/summarize-retrieval-review.py` 在导出前重新核对 182 个原始文件的哈希、3 份原始及 3 份修订报告、80 份原始 Pi 回执与 80 份答案复核包。媒体复核 v1 只对可验证原始内容版本的静态图片提供正向信用；音视频新观察仍需时间段/抽帧绑定评审，不凭模型描述自动授分。

验证：评测、复核与检索 API 相关 **70 项测试通过**；覆盖不可变回执、跨模式统一复算、证据合取、引用顺序、媒体占位与篡改、失败保留、未知语义分数、比较门禁和公开汇总的正文隔离。生产检索实现未改动。

## 后续优化重点

先补齐**独立问题、独立来源和最终答案的盲评**，并在新的保留集上比较相同阶段。新增问题应覆盖困难负例、跨来源证据、原始媒体和正确拒答；继续扩写少数文档中的类似问题，不能解决当前评测的偏差。

Pi 的实现优化应围绕可验证的剩余问题进行：记录候选池及选择前后变化，区分召回不足与后续证据选择；对证据未齐全的任务测试继续检索策略；评估预算接近耗尽时能否保留已验证成果并如实交付。原始查询约束、统一重排和模态保护需要分别做控制实验，不能依据这次标签修订直接声称有效。

真正的同预算对照还需采集器执行并记录契约中的限制。当前门禁检查所记录的控制条件，本身不会替检索器实施预算，也不能仅靠补写 `enforced: true` 把历史任务变成受控实验。
