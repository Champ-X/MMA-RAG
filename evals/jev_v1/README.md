# Jev reranking pilot v1

数据与真值在模型调用前冻结，`manifest.json` 固定 `cases.jsonl` 的 SHA-256。80 题：

- 项目原有 8 题：7 份完全合成文档；沿用原有三级 qrel。
- 自编 24 题：实体、作用域、旧版本、否定、注入、知识边界、反证、数字、条件、词汇陷阱、英文、中英混合；每类一题开发、一题留出。
- C-MTEB/T2Reranking 的 dev 第 100–147 行：前 8 题为本实验开发集，后 40 题为本实验留出集。**这里的 test 只是本实验拆分，不是数据集官方 test。** 每题最多取前 2 个 positive、前 18 个 negative，去重后随机打散；候选 ID 不暴露标签。

公开数据来源、下载时间、原始 rows 响应哈希见 [sources.json](../../docs/research/jev/sources.json)。公开数据的候选池和标注存在局限：`t2-113` 没有 positive，排序指标分母无定义，保留调用记录和分类诊断，但不纳入排序均值。公开留出排序统计因此是 39 题，总留出排序统计是 59 题。不会补造标签。

使用字符二元组 Jaccard 对固定候选预排序，映射为 `1/(61+rank)` 粗排分数，再执行项目实际候选选择、文档构建（1000 字符截断）、0.7 精排 + 0.3 粗排融合及最终排序。该 lexical 对照不是项目 Dense + Sparse + RRF 的端到端基线。配对模型输入完全相同，96 个文档在实际构建时被截断；结论限定于此配置。

运行、报告、逐题原始结果见 [研究与实验报告](../../docs/research/jev/README.md)。生成器 `backend/scripts/build_jev_dataset.py` 只用于可复现构造；更改输入/真值请升级数据集版本，不要覆盖已测基线。
