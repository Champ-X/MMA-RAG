# Baseline v1

这是一个完全合成的小型中文 RAG 评测集，不含生产、开发或用户知识库数据。

- 7 份短 Markdown 文档，每份聚焦一个主题，尽量稳定地产生单一检索单元。
- 8 个问题，覆盖单跳、多跳、流程、策略、安全、限制和应拒答的问题。
- qrel 相关度取 1–3；3 表示回答必需证据，1 表示有帮助但非必需的背景。
- manifest 固定每份语料的 SHA-256；修改正文、用例或 qrel 时应升级 `version`，不要静默覆盖既有基线。

运行和指标口径见 [`docs/RAG_EVALUATION.md`](../../docs/RAG_EVALUATION.md)。
